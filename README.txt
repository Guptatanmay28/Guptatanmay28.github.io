## Featured Work

### 1. Tata Motors — 5-Year Financial Performance & Valuation Analysis

A five-year consolidated financial analysis of Tata Motors covering **FY2022–FY2026**.

The project examines:

- Revenue and growth
- EBITDA and EBIT
- Profitability and margins
- EPS
- Assets and equity
- Debt and leverage
- Operating cash flow
- Capital expenditure
- Free cash flow
- Vehicle sales
- Valuation indicators

**Tools:** Microsoft Excel, Financial Analysis, Data Visualization

---

### 2. Fraud Detection & Transaction Risk Analysis

An end-to-end machine-learning project focused on identifying potentially fraudulent transactions and translating model predictions into practical risk decisions.

The project covers:

- Exploratory Data Analysis
- Data preprocessing
- Feature engineering
- Logistic Regression
- Random Forest
- Precision
- Recall
- F1-score
- ROC-AUC
- Feature importance
- Transaction risk classification
- Interactive risk dashboard

**Tools:** Python, Pandas, NumPy, Scikit-learn, Data Visualization

---

### 3. Retail Store Business Analytics Dashboard

An independent interactive dashboard focused on retail business performance and decision support.

The dashboard examines:

- Sales performance
- Business KPIs
- Product trends
- Transaction patterns
- Interactive business insights

**Tools:** Excel, Data Visualization, Dashboard Design
